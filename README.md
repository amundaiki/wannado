## 📝 Innhold

### 📱 Interaktiv Markedsplan
`index.html` - Komplett React-basert applikasjon med full funksjonalitet:

- **Interaktive menyer** med undermenyer og kategorier
- **16 produkter** med ekspanderbare kort og detaljert info
- **Sjekklister** som lagres automatisk i nettleseren
- **Månedlig årshjul** med detaljerte oppgaver, verktøy og kostnader
- **Ordforklaringer** med lenker og enkle forklaringer
- **Markedsføringsstrategier** per produkt
- **Responsive design** - fungerer perfekt på mobil og desktop
- **Lagring i nettleseren** - dine avkrysninger huskes

Den interaktive markedsplanen inneholder:
- Strategisk oversikt og team
- Alle 16 produktideer med full markedsføringsinformasjon
- Komplett årshjul fra oktober til september
- Markedsføringsbudsjett og ROI-beregninger
- Ordforklaringer for alle fagtermer

## 🛠️ Hvordan oppdatere innhold

Den interaktive markedsplanen er bygget med React direkte i `index.html`. For å oppdatere innhold:

1. Åpne `index.html` i en teksteditor
2. Finn JavaScript-delen inne i `<script type="text/babel">` taggen
3. Oppdater data-objektene for produkter, årshjul, eller annet innhold
4. Test endringene ved å åpne filen i nettleseren

### Viktige dataseksjoner i koden:

- **`produkter`** - Array med alle 16 produktideer
- **`arshjul`** - Månedlig handlingsplan fra oktober til september
- **`glossary`** - Ordforklaringer
- **`team`** - Informasjon om teammedlemmer
- **`budsjett`** - Markedsføringsbudsjett og kostnader

## 🎨 Design

Applikasjonen bruker:

- **React** for interaktivitet og state management
- **Tailwind CSS** for styling (via CDN)
- **LocalStorage** for å lagre brukerens avkrysninger
- **Responsive design** som tilpasser seg alle skjermstørrelser
- **Brune/beige jordfarger** som matcher Wannado's profil

## 📦 GitHub Pages oppsett

Nettsiden er satt opp for GitHub Pages:

1. `index.html` ligger i root (/) - dette er alt som trengs!
2. Ingen build-prosess nødvendig
3. Alt innhold er i én fil (inkludert React og Tailwind via CDN)
4. Fungerer direkte etter push til GitHub
