  <action>
1. **ContactForm.tsx - Add URL parameter pre-selection:**
   - Import `useSearchParams` from `next/navigation`.
   - Inside the component, read the `tjeneste` query param: `const searchParams = useSearchParams()` and `const preselectedService = searchParams.get("tjeneste")`.
   - If `preselectedService` matches one of the `serviceOptions` (case-insensitive comparison), set it as the default value of the service select element. Use a `defaultValue` prop on the `<select>` set to the matched option value (exact case from serviceOptions array), or `""` if no match.
   - Wrap the component export or the searchParams usage in a `<Suspense>` boundary. Since ContactForm is a client component using useSearchParams, the page that renders it must wrap it in `<Suspense>`. Add this wrapper in `kontakt/page.tsx` (see step 2 below), NOT inside ContactForm itself.
   - IMPORTANT: The select element currently uses `defaultValue=""`. Change this to use `defaultValue={matchedService || ""}` where `matchedService` is the resolved serviceOptions value matching the URL param, or null if no match.

2. **kontakt/page.tsx - Add Google Maps embed and Suspense wrapper:**
   - Import `Suspense` from `react`.
   - Wrap the `<ContactForm />` usage in `<Suspense fallback={<div className="bg-cream rounded-2xl p-6 md:p-8 h-[500px] animate-pulse" />}>`.
   - Add a Google Maps iframe embed in the right column, BELOW the existing "Oppmotesteder" card and ABOVE the "Tilgjengelig hele aret" card.
   - Use the no-API-key iframe embed approach: `https://www.google.com/maps?q=Skarestrand+11,+4812+Kongshavn,+Norway&output=embed`. This does NOT require a Google Maps API key.
   - Style the map container: wrap in a `<div>` with classes `bg-white rounded-2xl overflow-hidden shadow-sm border border-border`. The iframe itself should be `w-full h-64 md:h-72` with `border-0`, `loading="lazy"`, and `referrerPolicy="no-referrer-when-downgrade"`.
   - Add a heading inside the map card container: `<h3 className="font-space font-bold text-lg text-brown p-6 pb-0">Finn oss</h3>` above the iframe.

3. **Update service page CTA links to include ?tjeneste= parameter:**
   These pages have CTA links pointing to `/kontakt`. Update them to include the service query parameter:

   - `src/app/seilturer/page.tsx`: Change all `href="/kontakt"` to `href="/kontakt?tjeneste=Seilturer"`.
   - `src/app/kajakkturer/page.tsx`: Change all `href="/kontakt"` to `href="/kontakt?tjeneste=Kajakktur"`.
   - `src/app/teambuilding/page.tsx`: Change all `href="/kontakt"` to `href="/kontakt?tjeneste=Teambuilding"`.
   - `src/app/foredrag/page.tsx`: Change all `href="/kontakt"` to `href="/kontakt?tjeneste=Foredrag/JTI"`. URL-encode the slash if needed, but Next.js handles this automatically in the Link component.
   - `src/app/opplevelser/page.tsx`: Change `href="/kontakt"` to `href="/kontakt?tjeneste=Kajakktur"` (opplevelser is the general experiences page; Kajakktur is the primary offering).

   Do NOT change `/kontakt` links in Navbar.tsx or Footer.tsx (those are general navigation, not service-specific).
