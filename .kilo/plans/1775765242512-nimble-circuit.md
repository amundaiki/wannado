# Plan: Frontend Specialist Agent - Kilo

## Mål
Oppdater eksisterende `frontend-specialist` agent i Kilo med kunnskap fra to premium frontend-design repos:

1. **taste-skill** (Leonxlnx, 7.8k stjerner) - High-agency frontend med designvarianse, motion intensity, visual density
2. **impeccable** (pbakaus, 17.8k stjerner) - Design language med 21 commands, anti-patterns, typography, color, spatial, motion, interaction, responsive, UX writing

## Nåværende tilstand
Eksisterende `frontend-specialist` i `~/.config/kilo/kilo.json` har kun en grunnleggende prompt:
```
"You are a frontend developer expert in React, TypeScript, and modern CSS..."
```

## Plan

### 1. Hovedstruktur
Oppdater `frontend-specialist` agent med en omfattende prompt som inneholder:

#### A. Fra taste-skill
- **Design Variance** (1-10) - Layout asymmetri
- **Motion Intensity** (1-10) - Animasjonsnivå
- **Visual Density** (1-10) - Tetthet av innhold
- High-agency frontend regler
- CSS hardware acceleration
- Anti-slop guidelines
- Kreative arsenal (Bento grids, glassmorphism, etc.)

#### B. Fra impeccable
- **21 Commands** som agenten kan utføre:
  - `/audit` - Teknisk kvalitetssjekk
  - `/critique` - UX design review
  - `/normalize` - Align med design system
  - `/polish` - Final pass før shipping
  - `/distill` - Strip til essens
  - `/clarify` - Forbedre UX copy
  - `/optimize` - Performance
  - `/harden` - Error handling, i18n
  - `/animate` - Purposeful motion
  - `/colorize` - Strategisk farge
  - `/bolder` - Amplify kjedelige designs
  - `/quieter` - Tone down
  - `/delight` - Moments of joy
  - `/extract` - Pull into reusable components
  - `/adapt` - Adapt for different devices
  - `/onboard` - Onboarding flows
  - `/typeset` - Typography fixes
  - `/arrange` - Layout, spacing
  - `/overdrive` - Ekstraordinære effekter

- **7 Reference areas**:
  - Typography (fonts, scales, OpenType)
  - Color & Contrast (OKLCH, tinting, accessibility)
  - Spatial Design (4pt grid, container queries)
  - Motion Design (easing, stagger, reduced motion)
  - Interaction Design (focus states, forms, popovers)
  - Responsive Design (mobile-first, fluid)
  - UX Writing (labels, errors, empty states)

- **Anti-Patterns** (hva IKKE gjøre):
  - Side-stripe borders
  - Gradient text
  - AI-purple/blue aesthetics
  - Inter/system fonts
  - 3-column equal card layouts
  - Bounce/elastic easing
  - Generic names (John Doe)
  - etc.

### 2. Implementasjonssteg

**Fil å redigere:** `~/.config/kilo/kilo.json`

**Sekjsonstruktur:**
```json
{
  "agent": {
    "frontend-specialist": {
      "mode": "primary",
      "description": "Frontend Specialist - Premium UI/UX med taste-skill og impeccable",
      "prompt": "[MEGET LANG PROMPT med alt innhold]"
    }
  }
}
```

### 3. Permisjoner
Beholde eksisterende:
- read: allow
- bash: allow
- edit: kun frontend-filer (.tsx?, .jsx?, .css, .scss, .less)
- mcp: deny

### 4. Deliverables
- Oppdatert `frontend-specialist` agent i kilo.json
- Agenten skal kunne:
  - Generere premium frontend uten "AI slop"
  - Utføre design audits
  - Følge design system regler
  - Bruke riktige font-valg (ikke Inter)
  - Implementere fornuftige animasjoner
  - Skrive god UX-copy

## Brukervalg
- **Framework:** React/Next.js primary (RSC, Tailwind v3/v4, Framer Motion)
- **Commands:** Alle 21 commands fra impeccable

## Implementasjonsdetaljer

### Design-parametere (fra taste-skill)
```
DESIGN_VARIANCE: 6-8 (moderat asymmetrisk)
MOTION_INTENSITY: 5-7 (fluid men ikke kaotisk)
VISUAL_DENSITY: 4-6 (balansert)
```

### Font-anbefalinger (ikke Inter!)
- Display: Geist, Outfit, Cabinet Grotesk, Satoshi
- Body: Matchende sans-serif
- Mono: JetBrains Mono, IBM Plex Mono

### Farge-regler
- Max 1 accent color, saturation < 80%
- Bruk OKLCH, ikke HSL
- Ingen "AI purple/blue" gradienter
- Tint neutrals mot brand-hue

### Animations-regler
- ease-out-quart for entrances
- Spring physics (stiffness: 100, damping: 20)
- Prefixer-reduced-motion alltid
- Kun transform og opacity animeres

### De 21 Commands
```
/audit, /critique, /normalize, /polish, /distill, /clarify,
/optimize, /harden, /animate, /colorize, /bolder, /quieter,
/delight, /extract, /adapt, /onboard, /typeset, /arrange,
/overdrive, /impeccable teach, /impeccable craft
```

### Absolute Bans
- Side-stripe borders (>1px)
- Gradient text
- Pure black (#000) eller pure white (#fff)
- Inter/system fonts
- 3-column equal card layout
- Bounce/elastic easing
- Emojis i kode
- h-screen i stedet for min-h-[100dvh]
- Lucide icons uten standardisert stroke-width
